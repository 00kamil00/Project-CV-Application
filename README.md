# CV Application

> **Status:** 🚧 Work in Progress (Initial Setup)

This project is part of [The Odin Project](https://www.theodinproject.com/) curriculum (React Course). The goal is to build an interactive CV/résumé generator application using React, focusing on component structure, state management, and props handling.

---

## 🎯 Objectives & Features to Implement

- [ ] **Project Setup:** Initialize the React application structure.
- [ ] **General Information Section:**
  - Form inputs for name, email, and phone number.
- [ ] **Educational Experience Section:**
  - Form inputs for school name, title of study, and study dates.
- [ ] **Practical Experience Section:**
  - Form inputs for company name, position title, main responsibilities, and employment dates.
- [ ] **Form Interactivity:**
  - Implement dynamic Submit/Edit toggling to switch between display and edit modes without losing data.
- [ ] **Styling & Structure:**
  - Modular component hierarchy in `src/components/`.
  - Scoped styling in `src/styles/`.
- [ ] **Deployment:**
  - Deploy the live application to a hosting platform (e.g., Netlify, Vercel, or Cloudflare Pages).
